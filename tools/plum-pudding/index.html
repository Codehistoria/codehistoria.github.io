Plum pudding charts

Turn categories and values into coordinates for a circular waffle chart: dots packed inside a circle, grouped into slices that can be pulled apart, ready to plot in Tableau.

Runs entirely in your browser. Nothing you paste or open is uploaded or stored, and it is gone when you close the page.

Guides

Preparing an Excel file

The tool opens .xlsx, .xlsm, .xls and .ods workbooks, as well as CSV files. The file is read by this page on your own computer. It is not uploaded anywhere, and nothing is kept after you close the tab.

A layout that works

  1. One table per sheet, starting near the top left. A title line above the table is fine; it is skipped.
  2. Headings in the first row of the table. Recommended rather than required: you can tick or untick the headings box after opening.
  3. A column of labels: the categories that become slices.
  4. A column of numbers: counts, amounts or percentages. Other columns can stay; after opening, choose which columns to use.
  5. Or one row per item, such as one row per survey response, with no numbers at all. Choose Count rows and each label's rows are counted.

Things to avoid

  • Merged cells. Only the top-left cell of a merged block holds a value, so the rest read as blank. Unmerge and fill in the labels.
  • Several tables on one sheet. Give each table its own sheet, then switch between them with the Sheet menu.
  • Subtotals. A row labelled “Total” is left out automatically; other subtotal rows would be counted twice.
  • Text in the number column, such as “n/a”. Those rows are skipped and listed so you can check them.

Good to know

  • Formulas are fine: the tool reads the values Excel last calculated. Files made by other software sometimes lack saved results, so formula cells appear empty; opening and saving the file in Excel fixes this.
  • Percentages are read as decimals (45% as 0.45). That makes no difference to the chart, because only proportions matter. For One dot per unit, use whole numbers.
  • Repeated labels are added together, so raw rows work without a pivot table.
  • Hidden rows and columns are still read, and filters are not applied. Copy just the visible cells and paste them instead if you need a filtered view.
  • Password-protected files cannot be opened. Remove the password in Excel first.
  • Limits: 25 MB per file and 5,000 dots per chart.

Using it in Tableau
  1. Download the CSV and connect to it in Tableau as a text file.
  2. Drag X to Columns and Y to Rows, and put Dot ID on Detail so every dot is drawn separately. (Or untick Analysis › Aggregate Measures.)
  3. Set the mark type to Circle, put Category on Colour, and adjust Size.
  4. Keep the circle round. Tableau doesn't lock the aspect ratio, so fix both axes to the same range (suggested beside the preview), make the sheet square, then hide the axes and gridlines.
  5. Pack the dots. Tableau sizes marks in screen pixels, not axis units, so drag the Size slider until the dots match the preview; the panel suggests how wide each dot should be as a share of the chart. Then give the dashboard a fixed size, or resizing the window will open or close the gaps.
  6. Animated explode. X Base and Y Base hold the positions before exploding. Create a Boolean parameter Explode, then two calculated fields: 
    // X Plot
IF [Explode] THEN [X] ELSE [X Base] END
// Y Plot
IF [Explode] THEN [Y] ELSE [Y Base] END
    Plot those instead, and turn on Format › Animations for a smooth transition.
  7. Joining your own data. Join on Category, or use Dot ID as a fill order: with 100 dots, a flag such as [Dot ID] <= [Percent] shades that share of the circle, as in Kizley Benedict's original method.

How the numbers are worked out

Units. Every arrangement is scaled so the two closest dots are exactly 1 unit apart, centre to centre. A dot 1 unit across therefore just touches its nearest neighbour, and the space setting shrinks the dots from there. The circle is centred on (0, 0), and Y increases upwards, as in Tableau.

Spacing. The dots are drawn with diameter

D = 1 ÷ (1 + s)
D
the diameter of each dot, in coordinate units
s
the space between dots, as a share of a dot's width (0 = touching, 0.1 = a tenth of a dot)

In Tableau the dots should then be D ÷ (2A) of the chart's width, where A is the axis limit, because the axes run from −A to A.

Values to dots. Each category's exact share of the dots is

qi = N × vi ÷ V
qi
the exact, usually fractional, number of dots category i deserves
N
the total number of dots
vi
the value given for category i
V
the sum of all the values

Every category first gets qi rounded down. The dots left over go one at a time to the categories with the largest remainders (qi minus its rounded-down value). This is the largest-remainder or Hamilton method, used in seat apportionment; it guarantees the counts add up to exactly N.

From angle and distance to X and Y.

x = r × sin θ,   y = r × cos θ
r
the dot's distance from the centre of the circle
θ
its angle, measured clockwise from 12 o'clock (θ = 90° is 3 o'clock)

Concentric rings. Ring k sits at radius k × s and holds nk dots, shared out in proportion to k, because a ring's circumference grows with its radius. Its dots sit at θ = (m + ½) ÷ nk × 360°.

k
the ring's number, counting out from the centre (1, 2, 3 …)
s
the gap between rings, tuned so the spacing around each ring matches the spacing between rings
nk
the number of dots on ring k
m
a dot's position on its ring (0, 1, … nk − 1); the extra ½ centres the dots either side of the start angle

Sunflower spiral. Dot i is placed at

ri = c × √(i + ½),   θi = i × 137.508°
i
the dot's number, 0 to N − 1, from the centre outwards
c
a scale constant (about 0.525); afterwards the whole spiral is rescaled so its closest dots are 1 unit apart
137.508°
the golden angle, which stops the dots lining up into spokes

Grids. Points on a hexagonal or square grid with spacing 1 are sorted by distance from the centre, and the nearest N are kept.

Slices and exploding. Dots are sorted by angle from the start angle, and each category takes the next run of dots, so a category with a quarter of the dots fills roughly a quarter turn. Each slice is then moved outward along its centre line:

x′ = x + g × sin φ,   y′ = y + g × cos φ
x′, y′
the exploded position (the X and Y columns); x and y are the originals (X Base, Y Base)
g
the gap you set, in dot widths
φ
the angle of the slice's centre line, halfway between its first and last dot

Rings are exploded by adding g to each dot's distance from the centre for every gap inside it; rows by moving each group down by g for every gap above it.

CSV columns
Dot ID
1 to N, in fill order: the order in which the grouping hands dots to categories
Category
the label; Category Order is its position in the sequence
Value
the number given for the category; Dots is how many dots it received, and Share is Dots ÷ N
X, Y
the final, exploded position
X Base, Y Base
the position before exploding
Radius, Angle
the base position as distance from the centre and degrees clockwise from 12 o'clock

Your data and privacy

Everything happens in this browser tab. Pasted data and opened files are read by JavaScript on your own computer; nothing is sent to a server, saved to GitHub or kept after you close or reload the page.

The only things your browser downloads are the page itself and, the first time you open an Excel file, the open-source SheetJS library that reads it. Neither sends your data anywhere.

The one exception is Copy link: it puts your data inside the link so the chart can be recreated. Anyone you send that link to can see the data.
